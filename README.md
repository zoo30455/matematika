# Лёд — математика 4 יח״ל

Интерактивный курс повторения математики для 4 יח״ל.
Один самодостаточный HTML-файл: без сервера, без сборки, без зависимостей.

Прогресс хранится в браузере посетителя (localStorage) и никуда не отправляется.

## Запуск локально

Открыть `index.html` двойным кликом.

## Публикация

Любой статический хостинг. Настроено на GitHub Pages: включить
Settings → Pages → Deploy from branch → main → / (root).
